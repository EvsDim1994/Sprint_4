# Тесты для функционала работы с книгами

В данном проекте реализованы следующие тесты для проверки корректности работы с книгами и их жанрами:

1. **Тест для проверки названия книги длиной от 1 до 40 символов**  
   Проверяется, что книга с названием допустимой длины успешно добавляется в коллекцию.

2. **Тест для проверки названия книги длиной 0 или 41 символ**  
   Проверяется, что книга с пустым названием или названием длиной более 40 символов не добавляется.

3. **Тест для проверки добавления книги без жанра**  
   Проверяется, что книга может быть добавлена без указания жанра, и жанр по умолчанию отсутствует.

4. **Тест для установления жанра для добавленной книги**  
   Проверяется возможность задать жанр книги после её добавления.

5. **Тест для проверки добавления уже существующей в списке книги**  
   Проверяется, что повторное добавление книги с тем же названием не меняет состояние коллекции.

6. **Тест для получения книги по жанру**  
   Проверяется корректность получения списка книг, отфильтрованных по жанру.

7. **Тест для проверки добавления книги в список только для детей**  
   Проверяется, что книги с детским жанром корректно добавляются в соответствующий список.

8. **Тест для проверки добавления книги в Избранное**  
   Проверяется, что книга может быть добавлена в список избранных.

9. **Тест для проверки удаления книги из Избранного**  
   Проверяется, что книга может быть удалена из списка избранных.
